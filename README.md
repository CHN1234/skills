# Skills

个人 Codex Skills 仓库。

## Paper Author Studio

`paper-author-studio` 面向已经拥有 baseline 论文或代码、方法实现、实验脚本和结果，但需要将研究写成目标期刊或会议论文的场景。

它会：

- 从目标 venue 的同方向论文中提炼论证策略和表达习惯；
- 对照 baseline、用户代码和实验结果选择中心创新故事；
- 完成 Method、Experiments、Related Work、Introduction、Conclusion、Abstract 和 Title；
- 统一主张、证据、章节结构和作者声音。

在 Codex 中可让 `$skill-installer` 从以下目录安装：

```text
https://github.com/CHN1234/skills/tree/main/paper-author-studio
```

使用示例：

```text
$paper-author-studio 读取当前项目的 baseline、方法代码和实验结果，按目标期刊完成论文初稿。
```

仓库为私有仓库，安装者需要拥有访问权限。
