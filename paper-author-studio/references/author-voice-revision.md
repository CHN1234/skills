# 作者化重写

初稿完成后，把“内容齐全”提升为“像一位熟悉目标社区的资深作者做出的完整论证”。拟人化发生在选择、组织和表达中，不表现为角色扮演。

## Pass 1：中心故事统一

逐项对照：

```text
Title          说出最高层的中心思想或发现
Abstract       压缩同一条问题—方法—结果链
Introduction   提出 Method 真正解决的问题
Method         实现 Introduction 承诺的思想
Experiments    验证 Method 的核心主张
Related Work   建立该主张在文献中的位置
Conclusion     回答 Introduction 提出的问题
```

若章节在竞争不同论文身份，选择证据和 venue 适配度最强的一个，重写其余章节。

## Pass 2：恢复段落判断

为每段写一句隐藏摘要。如果两段承担同一任务则合并；一句摘要包含两个独立任务则拆分。

重写每段，使其形成自然链条：

```text
读者方向
→ 必要事实或证据
→ 作者解释
→ 对下一步的推动
```

首句优先说明段落为何存在。不要用 `We next...`、`To further...` 等程序性开场隐藏真正信息。

## Pass 3：迁移目标作者 DNA

根据 `venue-author-profile.md` 调整：

- 背景到问题的收束速度；
- 方法概览与技术细节的比例；
- 段落首句类型；
- 句长、从句和术语密度；
- 主动/被动语态与第一人称；
- 比较、解释、强调和限定的动词；
- 数字进入正文的频率；
- 贡献列表和章节标题的风格；
- 混合结果与局限的处理位置。

迁移的是统计规律和写作决策，不复制任何论文的特色句子或连续措辞。

## Pass 4：去模板化

删除或重写：

- 与当前研究无关的万能背景；
- 机械的三项贡献；
- `It is worth noting that` 一类无信息引导；
- 每段末尾重复结论；
- 连续相同的主谓结构；
- 把所有结果都称为显著、有效或优越；
- 只为听起来高级而存在的抽象名词；
- 由连接词维持、但没有逻辑关系的流畅句子；
- Introduction、Abstract 和 Conclusion 之间的近似复述。

目标不是制造随机变化，而是让每句话承担具体功能。

## Pass 5：语言精修

采用以下优先级：

```text
科学含义
> 论证关系
> 信息层级
> 清晰度
> 简洁度
> 节奏与风格
```

- 用同一个主要术语指代同一个概念；
- 用动词表达动作，减少名词堆叠；
- 一句话只承载一个主要逻辑关系；
- 重要结论直接陈述，再给证据；
- 有真实不确定性时说明不确定性的来源；
- 必要范围写成正面限定，不在高影响位置堆叠免责声明；
- 删除没有增加事实、逻辑或读者方向的句子。

完成后阅读全文，而不是只检查修改过的局部。作者声音必须跨章节一致。
